# Blood Bank Management System

## Description
A web application developed to manage blood bank data and blood donation requests.

## Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server

## Features
- Manage donor information.
- Search for donors by blood type.
- View available blood types and quantities.
- Submit blood donation and blood receiving requests.
- Perform CRUD operations.
- Validate user input.
